# Порівняння класичних моделей класифікації

## Постановка задачі
Задача бінарної класифікації: за клінічними показниками пацієнта визначити, чи є в нього серцеве захворювання. Позитивний клас: 1 (захворювання є). Основна метрика: F1 для класу 1, додаткові: Recall і ROC AUC. Для медичної задачі важливо не пропускати хворих, тому Recall розглядається окремо.

## Набір даних
Heart Disease (файл `data/heart_disease.csv`): 303 об'єкти, 13 ознак і цільова змінна `target`. Числові ознаки: age, trestbps, chol, thalach, oldpeak. Категоріальні ознаки: sex, cp, fbs, restecg, exang, slope, ca, thal. Пропуски є в ознаках ca (4) і thal (2).

## Методика експерименту
- фіксований train/test split 80/20 зі стратифікацією (random_state = 42): train 242 об'єкти, test 61 об'єкт;
- підбір моделей і параметрів лише на train;
- єдина StratifiedKFold (5 фолдів, shuffle, random_state = 42) для всіх порівнянь;
- одноразове фінальне оцінювання на test лише для однієї зафіксованої моделі.

## Підготовка даних
- SimpleImputer (найчастіше значення для категоріальних ознак);
- StandardScaler (числові ознаки);
- OneHotEncoder (категоріальні ознаки);
- ColumnTransformer;
- Pipeline.

## Досліджені моделі
- Logistic Regression;
- k-NN;
- Gaussian Naive Bayes;
- LDA;
- QDA;
- SVM.

Повні результати: `reports/cv_model_comparison.csv`.

## Фінальна модель і test-результат
Фінальна модель: логістична регресія (L2, C = 10, solver = liblinear) у складі Pipeline разом із попередньою обробкою. Модель обрана до відкриття test за правилом: найбільший CV F1, при рівності в межах стандартного відхилення вищий CV Recall. Логістична регресія має найвищий CV F1 (0.8363) і найменший розкид між фолдами (std 0.0127).

Одноразові результати на test (61 об'єкт): Accuracy 0.8689, Precision 0.8333, Recall 0.8929, F1 0.8621, ROC AUC 0.9621. Матриця помилок: TN 28, FP 5, FN 3, TP 25. Збережений Pipeline: `models/best_classifier.joblib`, метрики: `reports/final_test_metrics.csv`.

## Додаткові дослідження
Precision-Recall криві, детальний розбір помилкових test-об'єктів, калібрування ймовірностей і nested cross-validation. За nested CV логістична регресія (F1 0.8133) і LDA (F1 0.8128) практично рівні, а CV F1 з основної таблиці для моделей з підбором параметрів трохи завищений.

# pattern-recognition-practice

Практичні роботи з дисципліни «Розпізнавання образів і машинне навчання»

## Практична робота 1

**Тема:** Google Colab, GitHub і перше знайомство з даними.

У роботі використано набір даних Iris. Виконано:

- створення структури ML-проєкту;
- підключення Google Drive;
- завантаження та збереження набору даних;
- дослідження структури таблиці;
- отримання описової статистики;
- побудову розподілів ознак;
- формулювання задачі багатокласової класифікації.

[Відкрити Notebook](notebooks/PR01_Zboryk_Anton.ipynb)

## Практична робота 2

**Тема:** Дослідницький аналіз і підготовка даних.

У роботі виконано аудит якості пошкодженого набору Iris, очищення даних (дублікати, типи, категорії, пропуски, аномалії), дослідницький аналіз (гістограми, діаграми розмаху, розподіл класів, кореляції), кодування ознак і стратифікований поділ на навчальну й тестову вибірки.

## Практична робота 3

**Тема:** Перша модель і базове оцінювання якості.

У роботі виконано:

- формування навчальної й тестової вибірок;
- побудову DummyClassifier;
- побудову дерева рішень;
- отримання прогнозів;
- розрахунок accuracy, precision, recall і F1-міри;
- порівняння результатів на train і test;
- побудову матриці помилок;
- аналіз помилкових прогнозів;
- збереження навченої моделі.
